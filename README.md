# UserActivityMonitor

## Функционал

Клиент-серверное приложение для мониторинга активности пользователей Windows.

- Веб-интерфейс со списком клиентов: домен, компьютер, IP, пользователь, статус Online/Offline и время последней активности.
- Получение скриншота основного монитора по запросу.
- Windows-клиент с иконкой в трее, настройкой сервера и автозапуском при входе пользователя.
- Сохранение адреса сервера после первого запуска.

## Использование

Для сборки и запуска сервера нужен .NET 10 SDK. Команды выполняются из корня репозитория. Через --urls указывается адрес на котором будет работать сервер.

### Сервер

```bash
dotnet run --project src/UserActivityMonitor.Server --no-launch-profile --urls http://127.0.0.1:5031
```

Откройте `http://localhost:5031` в браузере.

### Клиент

Соберите один автономный EXE для Windows x64 (заранее собранный клиент находится GitHub Releases):

```bash
dotnet publish src/UserActivityMonitor.Client -c Release -o artifacts/client
```

1. Перенесите `artifacts/client/UserActivityMonitor.Client.exe` в постоянную папку Windows. Установка .NET на клиентском компьютере не нужна.
2. Запустите EXE, введите адрес сервера и сохраните настройки.
3. Клиент появится в трее и в таблице сервера. Автозапуск включается после первоначальной настройки.

Через меню трея можно изменить сервер, включить или отключить автозапуск и завершить приложение. Перед удалением EXE отключите автозапуск.

Настройки хранятся в `%LOCALAPPDATA%\UserActivityMonitor`. Для подключения с другого компьютера сервер должен слушать доступный сетевой интерфейс, например `--urls http://0.0.0.0:5031`.
